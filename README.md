# TPUDOCS — Complete Google Cloud TPU Knowledge Base (85 Official Docs + 9-Step Deployment Runbook)

End-to-end scraped, surgically cleaned, and structured repository of **all 85 official Google Cloud TPU documentation resources** plus the **Practical 9-Step NVIDIA-to-TPU Deployment Runbook**, provided in three formats:

1. **Clean Standalone Markdown (`markdown/`)** — 85 individual `.md` files + [`DEPLOYMENT_GUIDE.md`](DEPLOYMENT_GUIDE.md) (`1,390,538` clean chars, `2,000` sections, `1,092` fenced code blocks, zero navbar/footer noise).
2. **AI Agent Skill Format (`skills/`)** — **6 master workflow skills** (`skills/*/SKILL.md`), **86 per-resource catalog skills** (`skills/catalog/<category>/<id>/SKILL.md`), **5 category compendiums** (`skills/references/`), and **5 executable automation scripts** (`skills/scripts/`).
3. **Google Open Knowledge Format (`okf/`)** — **86 OKF v1.0 entity JSON-LD files** (`okf/entities/<category>/<id>.okf.json`) containing full extracted sections, code blocks, CLI commands, environment variables, tables, Q&A pairs, and semantic triples, plus the master knowledge graph [`okf/tpu_knowledge_graph.json`](okf/tpu_knowledge_graph.json) (`2,142` semantic triples).
