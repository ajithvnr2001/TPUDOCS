# Tokamax
[](https://github.com/openxla/tokamax#tokamax)
[![nightly](https://camo.githubusercontent.com/fc37160edc63086a6927b09f0c0c4d601eee9ef7771890efd8aa9eaaaa047399/68747470733a2f2f696d672e736869656c64732e696f2f6769746875622f616374696f6e732f776f726b666c6f772f7374617475732f6f70656e786c612f746f6b616d61782f63692d6e696768746c792e796d6c3f6c6162656c3d6e696768746c79266c6f676f3d676974687562616374696f6e73266c6f676f436f6c6f723d7768697465)](https://github.com/openxla/tokamax/actions/workflows/ci-nightly.yml) [![PyPI version](https://camo.githubusercontent.com/3a9956501ab5a4a2a5aea6fe9262e1a29f509b6a61b58e19c297abb02cdbe9f0/68747470733a2f2f696d672e736869656c64732e696f2f707970692f762f746f6b616d61783f636f6c6f723d626c7565)](https://pypi.org/project/tokamax/)
Tokamax is a library of custom accelerator kernels. It provides highly optimized implementations of key operators, including mixture-of-experts building blocks like grouped matrix multiplication and token gathers/scatters, attention variants like paged attention, splash attention, gated deltanet, Kimi delta attention and multiheaded latent attention, and TopK computation. The operator portfolio will evolve over time to support the latest OSS models running on the latest hardware accelerators, including Google [TPUs](https://cloud.google.com/tpu/docs/intro-to-tpu) and NVIDIA GPUs. The library also provides foundational infrastructure to simplify kernel authoring, maintenance, and deployment; for example, features like autotuning, low-overhead benchmarking, and so on.
Tokamax kernels are typically built on top of [JAX](https://docs.jax.dev/en/latest/index.html) and [Pallas](https://docs.jax.dev/en/latest/pallas/index.html), but also expose native PyTorch APIs on TPUs for developer convenience.
## Documentation
[](https://github.com/openxla/tokamax#documentation)
Detailed documentation can be found at [openxla.org/tokamax](https://openxla.org/tokamax/), including a list of [supported ops](https://openxla.org/tokamax/supported_ops) on different hardware accelerators, [benchmarking](https://openxla.org/tokamax/benchmarking) infrastructure, and [autotuning](https://openxla.org/tokamax/autotuning).

### Installation
[](https://github.com/openxla/tokamax#installation)
The latest Tokamax [PyPI release](https://pypi.org/project/tokamax/):

```
pip install -U tokamax
```

The latest bleeding edge version from Github, with no stability guarantees:

```
pip install git+https://github.com/openxla/tokamax.git
```
